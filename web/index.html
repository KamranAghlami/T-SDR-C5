t-sdr-c5

A pocket Wi-Fi spectrum waterfall for the LilyGO T-Display-C5. Install it from your browser.

Release notes

This browser can't talk to serial devices. Use Chrome, Edge or Opera on a desktop computer, or flash the release image with esptool.
Serial access needs a secure (https) page.

Steps

  1. Connect the board's antenna, then plug the board in over USB-C.
  2. Click Install and choose the board's serial port (often "USB JTAG/serial debug unit").
  3. Updating keeps your settings. Erase only for a clean install, if the page offers it.
  4. If the board isn't detected, hold BOOT, tap RST, release BOOT and try again.

After installing

Short presses on the two buttons step through channels; a long press on the USER button switches between 2.4 and 5 GHz; a long press on BOOT opens the settings. The full guide is in the README. The install dialog's Logs view shows the board's serial output.

Receive-only firmware built on ESP-SDR. Source (GPL-3.0).
